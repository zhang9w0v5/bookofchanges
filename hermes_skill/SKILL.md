# 易经卜卦（Book of Changes）

## 概述

通过金钱卦起卦，输出本卦、变卦、错卦、综卦、互卦、杂卦结果。

## 工具路径

本工具所有脚本位于：`~/.hermes/my_skills/skill_bookofchanges/`

- `bookofchanges.py` — 金钱卦起卦脚本

## 用法

### 命令行传参（AI 调用）

```bash
python3 ~/.hermes/my_skills/skill_bookofchanges/bookofchanges.py <卜卦之事>
```

自动起卦，结果保存到 `output` 子目录。

### 手动交互

```bash
python3 ~/.hermes/my_skills/skill_bookofchanges/bookofchanges.py
```

输入卜卦之事后，可选择自动起卦或手动摇掷三枚硬币（每爻掷三次，共六爻）。

## 输出

终端打印起卦时间、卜事、卦象 JSON，同时 `output` 子目录生成 `{YYYYMMDD_HHMMSS}_results.md`。

## JSON 结构

```json
{
  "六爻": [...],
  "本卦": { "卦理": "...", "上卦": "☰:乾:天", "下卦": "☷:坤:地", "<上象><下象>": "䷀:上乾下坤:天地否" },
  "主变": { "六爻之和": "...", "天地余数": "...", "主变爻序": "...", "主变爻位": "...", "主变变在": "...", "六九动爻": "...", "变动说明": "..." },
  "变卦": { "卦理": "...", "上卦": "...", "下卦": "...", "<上象><下象>": "..." },
  "错卦": { "卦理": "...", "上卦": "...", "下卦": "...", "<上象><下象>": "..." },
  "综卦": { "卦理": "...", "上卦": "...", "下卦": "...", "<上象><下象>": "..." },
  "互卦": { "卦理": "...", "上卦": "...", "下卦": "...", "<上象><下象>": "..." },
  "杂卦": { "卦理": "...", "上卦": "...", "下卦": "...", "<上象><下象>": "..." }
}
```

## 注意事项

- 各卦的 `上卦`/`下卦` 为 `卦象符号:八卦名:自然象` 三段式（如 `☰:乾:天`）
- 第 4 个 key 为动态字段：由 `上卦象+下卦象` 组合（如 `天地`、`风火`），值为六十四卦串（如 `䷀:上乾下坤:天地否`、`风火家人`），并非固定字段
- `六爻` 每爻为 `[数字]` 列表（3/2 分别表阳/阴）
